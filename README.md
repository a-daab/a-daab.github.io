# YOGAMATY™ — yogamaty.com

Static site (HTML/CSS/JS) for GitHub Pages, built from the three project documents (Concept Idea, Specification and Design Aesthetic documents, v2.0 Final, 14 October 2026). One small Cloudflare Worker handles the forms.

```
python3 tools/build.py          # regenerate /en/**, sitemap.xml, robots.txt, 404.html from src/ + data/
http-server -p 8080 .           # or any static server, to preview at http://localhost:8080/
node worker/test.mjs            # tests for the forms Worker (mock D1, mock mail)
python3 tools/check-placeholders.py   # what still has to be filled in before launch
```

Generated files (`en/`, `sitemap.xml`, `robots.txt`, `404.html`, `index.html`, `passport/`, `data/media.json`) are committed, because GitHub Pages serves the repository as-is. Edit `src/` and `data/`, then rebuild.

## Pages (Specification §2.2–2.3)

Header: **Shop** (Shop YOGAMATY · Wholesale & Studios) · How It Works · The Supply Chain · TransparaTrade · End Modern Slavery Now! (“The Movement” on narrow bars) · Our Story. Footer: Track Your Order · Supply-Chain Explorer · Whitepaper · FAQ · Become a Technical Ally · Contact · Privacy and Terms · Shipping and Delivery · Refunds and Cancellations. The petition lives on the End Modern Slavery Now! page. Old URLs (`/en/petition/`, `/en/about/`, `/en/privacy/`, `/en/terms/`, `/en/shipping-returns/`) forward via `src/redirects.json`.

## Where things live

| What | Where |
|---|---|
| Page copy and layout | `src/pages/en/*.html` (Jinja) · shared layout `src/templates/` |
| Nav, footer, form messages, passport UI strings | `src/i18n/en.json` (the `js` block is embedded for scripts) |
| Site settings (Stripe link, API URL, Turnstile key, noindex, sold-out) | `src/site.json` |
| Stage / record data (The Supply Chain page and the Explorer) | `data/tiers.json` (stage definitions) · `data/batches/<id>.json` (one per batch) · `data/standards.json` · `data/serials.json` |
| Motif artwork | `assets/motifs/*.svg` (generated by `tools/build_motifs.py` — **test-run art**) |
| Fonts | `assets/fonts/` — Mulish (variable) and Cormorant Garamond, self-hosted WOFF2, SIL OFL |
| Forms backend | `worker/` |

**Languages.** URLs are `/en/…` from day one. To add Nepali: create `src/i18n/ne.json` and `src/pages/ne/`, add `"ne"` to `languages` in `src/site.json`, rebuild. Note: nav/footer/forms/passport UI strings are in JSON; long-form page copy lives in the per-language page templates. Pair Mulish with Noto Sans Devanagari and Cormorant with Noto Serif Devanagari when adding it.

## The Supply-Chain Explorer (Tier Two)

One template renders any batch. To publish a batch: copy `data/batches/B-2026-04.json`, fill it in, set `"status": "published"`, commit. The git history is the dated record of when each claim was published. QR codes encode `https://yogamaty.com/passport/B-2026-04?mat=0137`; GitHub Pages has no routing, so `404.html` forwards that to `/en/explorer/?batch=…&mat=…`. The Supply Chain page itself is rendered at build time from `data/tiers.json` (stages A1–E5, each marked “planned” until records are published).

- `null` or a value starting with `[` renders as a highlighted `[ADD …]` placeholder.
- A value can be `{"v": "12", "estimate": true, "method": "…"}` — shown as an estimate with a “how this was measured” expander.
- Stages A6, B4 and C4 are `"powered": "confirm"` in `data/tiers.json`: kept in the data but **no powered/unpowered claim is published** until confirmed (Spec §4.6). Change to `true`/`false` when answered.
- Media: put processed files in `assets/media/passport/` named `A3-scraping-hands-01.webp` (tier ID first); rebuild and the tier shows them instead of the placeholder. `tools/process_media.py` resizes and strips EXIF. Keep raw `.ARW` files outside the repo.

## Going live — checklist

1. **Domain/Pages:** add a `CNAME` file containing `yogamaty.com` (or set the custom domain in Settings → Pages). Point DNS at GitHub Pages, enable *Enforce HTTPS*, turn on registrar privacy and auto-renew.
2. **Stripe:** create the product (retail price, quantity limit = batch capacity), a Payment Link collecting only name, email and shipping address (no phone, no pre-ticked marketing box), enable Stripe Tax with Connecticut registered, set the success URL to `https://yogamaty.com/en/shop/thank-you/`. Paste the link into `stripe_payment_link` in `src/site.json`. Ask Stripe about nonprofit rates; confirm tax treatment with an accountant.
3. **Forms Worker:** follow `worker/README.md` (D1 database, `RESEND_API_KEY`, `TURNSTILE_SECRET`, `api.yogamaty.com`). Then set `api_base` and `turnstile_site_key` in `src/site.json`. Fill `WHOLESALE_TO` and confirm `ALLIES_TO` in `worker/wrangler.toml`. Back up the petition (`wrangler d1 export`).
4. **Fill the placeholders:** `python3 tools/check-placeholders.py` lists them all.
5. **Legal:** have an attorney review `privacy`, `terms`, `shipping-returns` (drafts, bannered).
6. **Replace the test artwork** with the Nepali artists' SVGs (same filenames; see header of `tools/build_motifs.py` for conventions).
7. **Launch switch:** `python3 tools/set-indexing.py index`, then verify in Google Search Console.

## Decisions made while building the v2.0 revision (flag for the project lead)

- **Retail price is a placeholder** (`price` in `src/site.json`); the earlier $38 and the 260 g weight are withdrawn. Batch counter (`batch` in `src/site.json`) shows “Batch [N] — [x] of ~50 places taken” and a “this batch is full” state.
- Product is described everywhere as a **yoga mat towel/cover used on top of a conventional mat**; no grip, non-slip or durability claims; no “hundred-year-old looms”; electricity is stated per stage, never for the whole process.
- Hero headline and lede (“Free the world trapped behind the label…”) are kept from the earlier edit, with the brand spelled YOGAMATY™.
- **Buttons stay `#A34400`** (6.2:1 for 13px white text) rather than the `#CC5500` the Design document lists, because `#CC5500` is about 4.3:1 and the Specification requires WCAG 2.1 AA. Change `--btn-bg` to revert. Header bar remains 88% opacity with 12px blur (flagged “needs sign-off” in the Design document).
- The Specification says “Tier Two” for the per-piece record view; it is the **Supply-Chain Explorer** page and shows a clearly labeled template until a batch is published.
- Origin is now `https://yogamaty.com` (per the documents); the worker allows both apex and `www`.
- Only one studio photograph (flat overhead) is in the repo; the other four studio shots and the real logo/typeface files are still to be supplied. The header shows a fixed 160×32 “YOGAMATY™” placeholder.
- Illustrations remain test-run, AI-generated placeholders (site is `noindex`).
- Still open per the documents: price, finished weight, selling entity, regions, response time, wholesale inbox, hourly rate/benchmark, cancellation-after-production policy, return address, whitepaper file, Stripe link, forms Worker, legal review.
